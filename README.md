# 라리가 3개 팀 선수 성과 분석

레알 마드리드 · FC 바르셀로나 · 아틀레티코 마드리드의 최근 공식 10경기 기록으로
팀별 공격수 3 · 수비수 3 · 골키퍼 1명을 100점 만점으로 평가합니다.

## 실행 순서
1. `pip install -r requirements.txt`
2. api-football.com 에서 무료 가입 후 키 발급 (Account → My Access)
3. 키 설정
   - Windows(PowerShell): `$env:API_FOOTBALL_KEY="내키"`
   - Mac/Linux: `export API_FOOTBALL_KEY="내키"`
4. 분석 (3개 팀, 약 35회 호출 / 하루 무료 한도 100회)
   `python analyze.py "Real Madrid" "FC Barcelona" "Atletico Madrid"`
5. 화면 확인: `streamlit run app.py` (팀 이름을 입력해 바로 분석할 수도 있습니다)
6. PPT 생성: `python make_ppt.py laliga_analysis.pptx`

## 먼저 확인할 것
- 무료 플랜은 조회 가능한 시즌이 제한됩니다. 2026-27 시즌이 안 열리면 오류 메시지가 화면/터미널에 나옵니다.
  이 경우 유료 플랜(월 $19)이나 다른 데이터 소스가 필요합니다.
- 응답은 `.cache/`에 저장되어 같은 요청은 다시 호출하지 않습니다.

## 평가 기준 (config.py에서 조정)
- 선정: 포지션(F/D/G)별 출전 시간 상위 선수
- 공격수: 골 50% · 어시스트 30% · 성공한 패스 20% (모두 90분당)
- 수비수: 태클 35% · 가로채기 35% · 경합 승리 30% (90분당)
- 골키퍼: 선방률 40% · 실점 억제 30% · 클린시트 비율 30%
- 각 지표는 `기록 / 만점 기준값`(최대 1)로 환산 후 가중 합산. 기준값은 임의로 정한 값이므로 검토 후 바꾸세요.

## 알려진 한계
- API가 공중볼 경합만 따로 주지 않아 수비수는 '전체 경합 승리 수'로 대체했습니다.
- 패스 정확도는 API 필드(passes.accuracy)를 '정확한 패스 수'로 해석했습니다. 실제 응답으로 한 번 확인하세요.
- 이 코드는 실제 API 호출을 테스트하지 못했습니다(합성 데이터로 점수 계산과 PPT 생성만 검증).
